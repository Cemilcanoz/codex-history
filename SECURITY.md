# Security and privacy

Do not report a vulnerability with real session logs, API keys, `auth.json`, private prompts or index databases attached.

If GitHub private vulnerability reporting is enabled, use the repository's Security tab. Otherwise contact the maintainer through the contact information on their [GitHub profile](https://github.com/Cemilcanoz) before disclosing exploit details. A sanitized public issue is suitable for ordinary bugs that do not expose secrets or an active vulnerability.

The application is an early preview. Only the latest published version receives fixes. It reads explicitly selected local sources and does not upload session data; workspace paths and other metadata remain sensitive. Content preview is opt-in and does not redact secrets.
